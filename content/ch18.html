18.1 Файловые потоки

Для работы с файлами в C++ используются потоки из <fstream>. Три основных типа:

  • std::ifstream — входной поток (чтение из файла);
  • std::ofstream — выходной поток (запись в файл);
  • std::fstream — двунаправленный (чтение и запись).

Файл можно открыть при создании объекта или методом open():

Файловый поток автоматически закрывается при выходе из области видимости (это RAII, глава 25). Явный close() не обязателен, но полезен, чтобы освободить файл прямо здесь и сейчас.

Если файл не найден (при чтении) или не удалось создать (при записи), поток переходит в состояние ошибки. Всегда проверяй, открылся ли файл!

Каждый запуск в этой песочнице получает свою чистую временную папку, которая удаляется после завершения: можно записать файл и тут же прочитать его обратно, но между запусками файлы не сохраняются. Пример выше специально упадёт с «Cannot open file!» и кодом 1: файла data.txt нет.

18.2 Чтение

Те же способы, что и с std::cin:

  • >> — по словам (до пробела или новой строки);
  • std::getline() — по строкам (с пробелами);
  • get(), read() — побайтово.

Цикл while (in >> x) корректно завершается при достижении конца файла или ошибке: поток в условии приводится к bool.

while (!in.eof()) { in >> x; sum += x; } обработает последнее число дважды (или мусор): флаг eof выставляется только после неудачной попытки чтения. Правильно — проверять результат самого чтения: while (in >> x).

18.3 Запись и режимы открытия

По умолчанию std::ofstream перезаписывает файл. Чтобы дописывать в конец, нужен флаг std::ios::app: std::ofstream out("log.txt", std::ios::app);

Режимы задаются битовыми флагами (помнишь | из главы 5?):

ФлагСмысл
std::ios::inчтение (по умолчанию у ifstream)
std::ios::outзапись (по умолчанию у ofstream)
std::ios::appдописывание в конец
std::ios::binaryдвоичный режим вместо текстового

Режим app — стандартный способ писать логи: каждый запуск сервиса дописывает свои строки, не стирая чужие. А binary нужен для картинок, архивов и любых «не текстовых» данных: в текстовом режиме на Windows '\n' при записи превращается в "\r\n", и бинарник ломается.

Программа каждый запуск пишет строку в log.txt через std::ofstream out("log.txt");. Почему в файле всегда только одна строка?
  1. Файл не закрывается
  2. По умолчанию ofstream перезаписывает файл; нужен std::ios::app
  3. Нужно писать std::endl вместо '\n'
Режим out без app обрезает файл при открытии.
