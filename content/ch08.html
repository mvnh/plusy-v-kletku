Операция (operator) — символ или ключевое слово, обозначающее действие над операндами: +, =, <, ++. Оператор (statement) — законченная команда языка: if, while, return, a = b + c;. В этой главе у нас есть и то и другое для «если», и разница здесь принципиальна.

8.1 Условная операция ?:

В C++ есть единственная тернарная операция (принимает 3 аргумента) — условная ?:.

<bool-expr> ? <expr1> : <expr2>, где

  1. bool-expr — выражение, конвертируемое в bool;
  2. expr1, expr2 — выражения с совместимыми типами (есть общий тип, к которому оба неявно приводятся).

Если bool-expr истинно, вычисляется expr1, иначе — expr2.

  • Операция всегда возвращает значение, оператор — нет.
  • Операция — часть выражения, оператор — самостоятельная единица.

Пример 1.63. На вход неотрицательные целые x и y. Вывести x / y, если y != 0, иначе −1.

UB здесь нет: x / y вычисляется только при y != 0. Поставь во ввод 17 0 и проверь.

Пример 1.64. То же, но вместо −1 вывести Error:

Ошибка: operands to '?:' have different types 'int' and 'const char*'. У int и строкового литерала нет общего типа, нет неявного преобразования одного в другое.

Результат условной операции — общий тип, к которому можно безопасно привести оба операнда. И он не зависит от истинности условия: типы разрешаются при компиляции, а не во время выполнения.

  1. Типы одинаковые — это и есть общий тип.
  2. Один операнд неявно приводится к типу другого — общий тип равен типу второго.
  3. Иначе компилятор ищет общий тип через стандартные преобразования.
  4. Типы несовместимы (int и const char*) — ошибка компиляции (CE).
Что выведет программа?
Общий тип double и int — double. Условие истинно: 3 / 2.0 = 1.5.
А так? Условие ложно, но тип у результата всё равно общий…
Выбирается 1, но приводится к общему типу double. Печатается 1: cout не показывает «.0» у целых значений double. Подвох в том, что тип всё-таки double, а не int.

Вспомни про запятую и про то, что будет у x++ + ++x при x = 0. Намёк: порядок вычисления операндов + не гарантирован, и два изменения одной переменной в одном выражении без точки следования — UB.

А вот условная операция гарантирует порядок: 1) сначала вычисляется bool-expr; 2) затем только один из expr1/expr2. Это логично и позволяет избежать UB в примерах вроде y != 0 ? x / y : -1.

Категория значения результата

Условная операция возвращает lvalue, если оба операнда — lvalue одного типа (с точностью до cv-квалификаторов). Тогда результат ссылается на первый или второй операнд:

Если хотя бы один операнд rvalue или типы разные, результат — rvalue, присвоить нельзя:

  • Оба — lvalue одного типа (с точностью до const/volatile) → lvalue того же типа.
  • Категории различаются (lvalue и rvalue) → rvalue.
  • Категории совпадают, типы отличаются только cv-квалификаторами (int и const int) → категория сохраняется, тип объединяется (const int).
  • Типы разные (даже после неявных преобразований) → prvalue общего типа.

Стандарт делит rvalue на prvalue (pure rvalue: литералы, результаты функций, возвращающих по значению) и xvalue (expiring value: объекты, которые вот-вот уничтожатся и из которых можно «переместить» данные, например результат std::move). Пока для простоты используем только lvalue и rvalue, где rvalue — всё, что не lvalue.

8.2 Условный оператор if

if ([init] <condition>) <statement-true> [else <statement-false>]

  • condition — выражение, конвертируемое в bool;
  • statement-true — выполняется, если condition истинно;
  • statement-false — выполняется, если ложно;
  • init — выражение или объявление (C++17). Объявленная сущность живёт в области условного оператора. Может отсутствовать.

Ветку else можно опустить, условные операторы можно вкладывать друг в друга.

Фигурные скобки:

  • можно не ставить, если выполняется один оператор;
  • рекомендуется ставить всегда — читаемость и защита от ошибок;
  • создают новую область видимости.

Если объявляешь переменную в condition, её обязательно инициализировать:

if с инициализацией (init)

В продакшене if с init живёт рядом с поиском: if (auto it = cache.find(key); it != cache.end()) { … } — итератор не «утекает» за пределы проверки. Аккуратно и без мусорных переменных в функции.

else и вложенные условия

Максимум из трёх чисел вложенными if:

else относится к ближайшему неспаренному if.

  • Отступы в C++ не влияют на выполнение (в отличие от Python).
  • Без {} после if/else условие относится только к одному ближайшему оператору.
  • Всегда ставь скобки!
Что выведет программа?
Несмотря на отступ, else принадлежит ближайшему if (y > 0). x > 0 — входим, y > 0 ложно — срабатывает else: B.

В C++ нет ключевого слова else if или elif. else if — это просто else, за которым сразу идёт другой if:

Apple, 2014, баг «goto fail» в проверке SSL-сертификатов: строка goto fail; случайно продублировалась после if без фигурных скобок. Вторая копия выполнялась всегда, и проверка подписи пропускалась. Миллионы iPhone и Mac принимали поддельные сертификаты. С фигурными скобками баг был бы невозможен.

8.3 Оператор switch

switch ([init] <condition>) statement — выбор ветки по значению выражения.

  • init — выражение или объявление, как у if;
  • condition — выражение целого или перечислимого типа, либо объявление одной такой переменной с обязательной инициализацией;
  • statement — произвольный оператор, обычно составной с метками case, default и операторами break.

Метки: case <const-expr>: <statements> и default: <statements>. const-expr — константное выражение, вычисляемое при компиляции, целого или перечислимого типа. Значения в case должны быть уникальными.

После вычисления условия ищется подходящая метка, и управление передаётся на первую инструкцию после неё. Нет подходящей — переход к default.

После перехода к метке выполняются все операторы ниже, даже под другими метками. Чтобы остановиться, нужен break;.

Где switch царствует: интерпретаторы и эмуляторы (большой switch по коду инструкции байт-кода), конечные автоматы в сетевых протоколах и парсерах, обработка нажатых клавиш в играх. Проваливание иногда используют намеренно: знаменитый «Duff's device» вручную разворачивает цикл через switch с проваливаниями.
