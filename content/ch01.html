C++ появился из C и сейчас живёт в стандарте C++23. Сначала разберём, как текст программы превращается в работающую программу и из каких «кирпичиков» он состоит. Потом напишем главную программу всех времён.

  • C (1969/1972) — прародитель. Деннис Ритчи, Bell Labs, писали под системное программирование и UNIX.
  • C with classes (1979) — Бьёрн Страуструп добавил к скорости C классы, наследование, инкапсуляцию.
  • C++ (1982/83) — официальное имя. «++» — инкремент из C. Мемы про то, что инкремент постфиксный (то есть язык возвращает старое значение), прилагаются.
  • C++98 — первый стандарт ISO/IEC 14882:1998: STL, пространства имён, RTTI.
  • C++11 — «новый C++»: auto, лямбды, range-based for, умные указатели, move-семантика. Многое из курса — отсюда.
  • C++17 — структурные привязки, std::optional, std::variant, filesystem, параллельные алгоритмы.
  • C++20 — модули, концепты, корутины, ranges, оператор <=>.
  • C++23 — стандарт нашего курса (C++26 уже есть, но для базы разница небольшая).

Почему C++ выбирают до сих пор: максимальный контроль над памятью, предсказуемая производительность, низкоуровневые оптимизации, совместимость с C и старым кодом. На нём частично написаны Windows, macOS, Chrome, Firefox, YouTube, Photoshop, Telegram и другие языки программирования.

Открой Chrome: движок отрисовки Blink и JS-движок V8 написаны на C++. Unreal Engine (Fortnite и половина AAA-игр) — C++. ClickHouse (родом из Яндекса), аналитическая СУБД, которая жуёт миллиарды строк в секунду, — C++. Клиентская библиотека Telegram TDLib — C++. Везде, где важны миллисекунды и байты, обычно стоят «плюсы».

Язык коварен, но если понять его логику, коварство исчезает: почти всё в нём объяснимо.

1.1 Запуск программ на C++

C++ — компилируемый язык. Текст программы сначала обрабатывает специальная программа — компилятор. Он переводит код в машинные инструкции и создаёт исполняемый файл, который потом запускается как любая другая программа.

Примеры компилируемых языков: C, C++, Basic, Go, Pascal, Rust…

Интерпретируемые языки подают текст программы другой программе — интерпретатору, который сразу исполняет код без сборки исполняемого файла. Примеры: Python, PHP, Perl, Ruby.

Бывает и гибрид: например, Java компилируется в байт-код, который потом исполняет виртуальная машина.

Аналогия: компилятор — переводчик, который перевёл книгу целиком, и дальше ты читаешь готовый перевод сколько угодно раз. Интерпретатор — синхронист, который переводит каждую фразу заново при каждом прочтении.

Кодом на C++ является любой текстовый файл, написанный по правилам языка. Чтобы сделать из него программу, его надо скомпилировать. На этой платформе это происходит прямо в браузере: внутри работает настоящий компилятор clang, собранный в WebAssembly. Жми «запустить» у любого примера.

Ты поменял одну строчку в программе на C++. Что надо сделать, чтобы изменения заработали?
  1. Ничего, исполняемый файл обновится сам
  2. Перезапустить интерпретатор
  3. Скомпилировать программу заново и запустить новый исполняемый файл
Исполняемый файл — «снимок» кода на момент компиляции. Поменял код — компилируй снова.

1.2 Состав языка C++

Язык состоит из набора базовых элементов, которые складываются в программу по строгим правилам. Идём снизу вверх: символы → слова → конструкции.

Алфавит

Алфавит C++ — набор символов, из которых может состоять программа.

  1. Цифры 0 … 9
  2. Латинские буквы a … z, A … Z
  3. Нижнее подчёркивание _
  4. Пробельные символы и перенос строки
  5. Скобки: фигурные {} (блоки кода, инициализация), круглые () (вызовы функций, выражения), квадратные [] (массивы, захваты лямбд), угловые <> (шаблоны, сравнения)
  6. Кавычки: двойные "Hello" — для строк, одинарные 'A' — для символов

Ключевые слова

Ключевые слова — слова с особым значением в языке.

Зубрить не надо, многие ещё встретим: alignas, alignof, and, auto, bool, break, case, catch, char, class, const, constexpr, continue, default, delete, do… Полный список и вообще истина в последней инстанции — на cppreference.

Идентификаторы

Идентификатор — имя программного объекта (переменной, функции, типа…).

Идентификатор — последовательность букв, цифр и _, где:

  1. первый символ не цифра;
  2. нет пробелов;
  3. это не ключевое слово;
  4. регистр важен: Alice и alice — разные имена.
Упражнение 1.1 из конспекта. Отметь допустимые идентификаторы.
  1. alla
  2. allo4ka
  3. allochka-ivanova
  4. allo4ka_ivanova
  5. allochka ivanova
  6. 2dima
  7. _
  8. _2dima
  9. asm
  10. AsM
allochka-ivanova — дефис это минус, выйдет выражение «allochka минус ivanova». allochka ivanova — пробел. 2dima — начинается с цифры. asm — ключевое слово (вставка ассемблера). А вот AsM — можно: регистр важен, и это уже не ключевое слово. _ и _2dima — тоже законны (хотя имена, начинающиеся с _ и большой буквы или с __, зарезервированы за реализацией — лучше так не называть).

Константы (литералы)

Литералы — значения, вписанные прямо в текст программы.

  • Целые, причём в разных системах счисления: десятичные 123, восьмеричные 045, шестнадцатеричные 0x1A, 0XBD, двоичные (C++14) 0b101, 0B1001
  • Символьные — 'a', '\n'
  • Вещественные — 3.14, .24e10
  • Строковые — "a", "This is string"
  • Логические — true, false
  • Нулевой указатель — nullptr

Ведущий ноль делает число восьмеричным: 045 — это 37, а не 45. Классика багов, когда кто-то «красиво выровнял» номера через нули.

Операции

Операция (operator) — символ или ключевое слово, выполняющее действие над одним или несколькими операндами: +, -, *, /, =, == и т.д.

У каждой операции есть:

  • арность — сколько аргументов она принимает;
  • приоритет — определяет порядок вычисления разных операций;
  • ассоциативность — порядок выполнения операций с одинаковым приоритетом (слева направо или справа налево).

Один и тот же знак может иметь разный смысл, арность и приоритет в зависимости от количества операндов и типов.

  • Оператор (statement) — законченная команда: объявление переменной, присваивание, условный оператор, цикл, return.
  • Операция (operator) — символ/слово, действующее на операнды внутри выражения.

В русской литературе «operator» часто тоже переводят как «оператор», отсюда путаница. В этом курсе различаем строго, и на экзамене это любят спрашивать.

Чем в строке -a - b отличаются два минуса?
  1. Ничем, это одна и та же операция
  2. Первый — унарный (арность 1, приоритет выше), второй — бинарный (арность 2)
  3. Первый — оператор (statement), второй — операция
Знак один, операции разные: унарное отрицание и бинарное вычитание. У унарного минуса приоритет выше, поэтому сначала -a, потом вычитание.

Число, которое возвращает main, операционная система воспринимает как код завершения (exit code). Традиция «0 = успех» пришла из UNIX (1969): 0 — успешное завершение, 1 или любое ненулевое — ошибка. POSIX закрепил это как EXIT_SUCCESS = 0 и EXIT_FAILURE = 1. А стандарт C++ гарантирует: если main не вернула значение явно, компилятор сам вставляет return 0.

  • Стандарт разрешает опускать return 0 в main. main — единственная функция, где так можно.
  • В других функциях, которые должны вернуть значение, отсутствие return — неопределённое поведение (UB).
  • Некоторые компиляторы требуют явный return даже в main. Явный return 0; — хороший тон.

Коды возврата — не археология. Любой CI (GitHub Actions, GitLab CI) считает шаг упавшим, если команда вернула не 0. make останавливает сборку на первом ненулевом коде. Так что return 1; из твоей утилиты буквально может «покрасить» пайплайн в красный.

1.4 Структура программы

Объявление (declaration) — введение (создание) некоторой именованной сущности.

Это «декларация о намерениях»: такая функция будет, и её можно использовать. Это объявление без определения. В общем случае объявления лишь вводят новые имена, но не дают им конкретного смысла.

Определение (definition) — объявление с полной информацией о создаваемой сущности.

В программе должно быть ровно одно определение main. Не определить main вообще тоже нельзя.

Директивы препроцессора — вспомогательные инструкции, которые начинаются с # и манипулируют текстом программы ещё до компиляции.

Функции описывают последовательность действий, которые выполняются по порядку, сверху вниз. Вспомни определение оператора: пока мы знаем один — оператор возврата return. Некоторые операторы требуют вычислений, а за вычисления отвечают выражения.

Выражение (expression) — последовательность операций и их операндов, задающая вычисление. У любого выражения есть результат (может быть пустым), который подставляется вместо него.

Комментарий — текст кода, который игнорируется при сборке программы.

В Java Unicode-эскейпы обрабатываются до разбора комментариев, поэтому возможен «исполняемый комментарий»:

\u000d — перевод строки (carriage return). Компилятор Java сначала заменяет эскейпы, потом ищет комментарии, и System.out.println «выпадает» из комментария на новую строку и исполняется. В C++ так не работает: комментарии полностью игнорируются, эскейпы внутри них не обрабатываются.

1.6 Самая важная программа

'\n' — символьная константа (ASCII 10). Просто добавляет перевод строки в поток. Быстро.

std::endl — манипулятор потока из <iostream>: 1) добавляет \n; 2) вызывает std::flush() — сбрасывает буфер. Медленнее из-за сброса.

Когда что: '\n' — почти всегда: циклы с большим выводом, высокопроизводительный код, обычный перевод строки. std::endl — когда нужен немедленный вывод: индикатор прогресса, лог-файлы, гарантия, что сообщение появится прямо сейчас.

Буферизация пришла из C и операционных систем. Сброс буфера гарантирует, что данные реально записаны в устройство: на экран, в файл, в сеть.

На олимпиадах и в LeetCode-подобных системах std::endl в цикле на миллион строк легко превращает «Accepted» в «Time Limit Exceeded»: миллион системных вызовов вместо пары десятков. Поэтому в спортивном программировании пишут '\n' и иногда ещё std::ios::sync_with_stdio(false);.

Программа выводит прогресс-бар загрузки, и проценты должны появляться на экране сразу. Что использовать в конце строки?
  1. std::endl (или явный std::flush)
  2. '\n' — он быстрее
  3. Без разницы
Нужен немедленный вывод — значит, надо сбросить буфер. Это ровно случай для std::endl/std::flush.
