5.1 Поразрядные битовые операции

Вспомним операции, которые работают напрямую с битами чисел. Каждый бит результата считается независимо от соседей.

ОперацияНазваниеБит результата = 1, когда…
&AND (И)оба бита 1
|OR (ИЛИ)хотя бы один бит 1
^XOR (исключающее ИЛИ)биты разные
~NOT (НЕ)бит был 0 (инверсия)
<<сдвиг влевобиты едут влево, справа приходят нули
>>сдвиг вправобиты едут вправо

Все комбинируются с присваиванием: &=, |=, ^=, <<=, >>=.

Примеры из конспекта на short (16 бит). Выбери операцию в виджете, там уже стоят те же числа:

Свойства XOR

  • a ⊕ a = 0
  • a ⊕ 0 = a
  • a ⊕ b = b ⊕ a (коммутативность)
  • (a ⊕ b) ⊕ c = a ⊕ (b ⊕ c) (ассоциативность)

Из них следует магия: если XOR-нуть все числа массива, где каждое встречается дважды, а одно — один раз, останется ровно одиночка. Пары взаимно уничтожатся. Это задача «Single Number» с LeetCode, она ждёт тебя в тренажёре.

Сдвиги

Для беззнаковых чисел сдвиг влево на n разрядов — это умножение на 2n, а сдвиг вправо — целочисленное деление на 2n.

Для знаковых чисел сдвиг вправо арифметический: знак сохраняется, слева «приезжают» копии старшего бита.

По конспекту: поведение сдвига вправо отрицательных чисел зависит от компилятора, но большинство делают арифметический сдвиг. Для полноты: начиная с C++20 стандарт закрепил дополнительный код, и >> для отрицательных теперь гарантированно арифметический. UB остаётся, если сдвигать на отрицательное число разрядов или на ширину типа и больше: 1 << 32 для 32-битного int — UB.

Заметь: -87 >> 3 = −11, а -87 / 8 = −10. Арифметический сдвиг округляет вниз (к −∞), а деление — к нулю. Для отрицательных это разные операции!

Что выведет std::cout << (-87 >> 3) << ' ' << (-87 / 8);?
Сдвиг: −10,875 округляется к −∞ → −11. Деление: к нулю → −10.

5.2 Битовые хитрости

Конспект советует отдельно изучить битовые трюки. Вот база, которую реально спрашивают и используют:

ЧтоКакПочему работает
Проверить k-й бит(x >> k) & 1сдвинули нужный бит в младший разряд
Установить k-й битx |= (1 << k)OR с маской, где единица только в k
Сбросить k-й битx &= ~(1 << k)AND с маской, где ноль только в k
Переключить k-й битx ^= (1 << k)XOR с 1 переворачивает бит
Чётностьx & 1младший бит = остаток от деления на 2
Степень двойки?x > 0 && (x & (x - 1)) == 0x - 1 гасит единственную единицу
Младшая единицаx & -x-x = ~x + 1
Обмен без tempa ^= b; b ^= a; a ^= b;свойства XOR (ломается при &a == &b!)

Где это живёт в реальном коде:

  • Права доступа в Linux: chmod 755 — это три тройки битов rwx. Внутри ядра проверка «можно ли писать» — буквально mode & S_IWUSR.
  • Шахматные движки (Stockfish и др.) хранят доску как 64-битные «битборды»: один uint64_t = все белые пешки. Ходы считаются сдвигами и масками за наносекунды.
  • Флаги в API: std::ios::in | std::ios::binary из главы о файлах — это OR битовых масок.
  • Хэш-таблицы с размером 2k берут индекс как hash & (size - 1) вместо медленного %.
Как сбросить (обнулить) 3-й бит переменной flags, не трогая остальные?
  1. flags ^= 3;
  2. flags &= (1 << 3);
  3. flags |= ~(1 << 3);
  4. flags &= ~(1 << 3);
Маска ~(1 << 3) — все единицы, кроме 3-го бита. AND с ней обнуляет только его. Вариант B, наоборот, обнулит всё кроме 3-го бита.
Что выведет std::cout << ((48 & 47) == 32);?
48 = 110000, 47 = 101111, AND = 100000 = 32 → true → 1. 48 не степень двойки: после гашения младшей единицы осталась ещё одна.
