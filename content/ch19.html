Многомерный массив — массив, элементы которого сами являются массивами. Чаще всего встречается двумерный (матрица, таблица), но бывают и трёх-, и четырёхмерные.

В C++ многомерные массивы — это массивы массивов. Способ создания (статический или динамический) кардинально влияет на расположение в памяти.

19.1 Статические многомерные массивы

Матрица int a[3][3] логически выглядит как таблица:

столбец 0столбец 1столбец 2
строка 0a[0][0]a[0][1]a[0][2]
строка 1a[1][0]a[1][1]a[1][2]
строка 2a[2][0]a[2][1]a[2][2]

Статический массив хранится единым непрерывным блоком, построчно (row-major). Для int a[3][3] выделяется 3 × 3 × sizeof(int) байт подряд:

[0][0] [0][1] [0][2] │ [1][0] [1][1] [1][2] │ [2][0] [2][1] [2][2]

Поэтому &a[0][0] + 1 == &a[0][1] и &a[0][2] + 1 == &a[1][0].

Многомерный массив неявно преобразуется к указателю на свой первый элемент, который сам является массивом:

sizeof(arr) для int arr[N][M] возвращает N * M * sizeof(int) — в отличие от динамического массива, где получится размер указателя.

Обход по строкам для больших матриц быстрее в разы: соседние элементы строки лежат рядом и попадают в кэш процессора одной загрузкой. Обход по столбцам прыгает по памяти с шагом в целую строку. На матрице 4000×4000 разница легко бывает 3–10×, хотя операций ровно столько же. Поэтому в numpy и библиотеках линейной алгебры так трясутся над row-major и column-major.

19.3 Квадратные матрицы

Квадратная матрица — двумерный массив n × n: строк столько же, сколько столбцов.

  • Главная диагональ — индекс строки равен индексу столбца: a[i][i].
  • Побочная диагональ — сумма индексов равна n − 1: a[i][n - 1 - i].
a00a01a02a03
a10a11a12a13
a20a21a22a23
a30a31a32a33

Красным — главная диагональ, синим — побочная.

Индексы диагоналей работают только для квадратных матриц. Для прямоугольных понятия «главной» и «побочной» диагонали в строгом смысле не определены.

Упражнение 19.2. Функция void printDiagonals(const int* const* matrix, int n); выводит обе диагонали. Тип const int* const* предполагает матрицу как «массив указателей»:

Если матрица хранится одномерно (int* data = new int[n*n]): главная диагональ — data[i * n + i], побочная — data[i * n + (n - 1 - i)].

Сколько элементов матрицы 4×4 лежат одновременно на главной и на побочной диагонали?
Пересечение — это i == n - 1 - i, то есть i = (n - 1) / 2. Целое решение есть только при нечётном n. Для 4×4 — 0 элементов, для 5×5 — один, центр a[2][2]. Поэтому в задачах «сумма обеих диагоналей» для нечётного n центр нельзя посчитать дважды.

19.4 Заполнение матриц

Частая задача — заполнить матрицу по паттерну. Самые популярные — «змейки» и спираль. Жми «заполнить» и следи за порядком:

Змейка по строкам (горизонтальная)

Слева направо в чётных строках, справа налево — в нечётных. Для позиции (i, j) в матрице n × m:

значение = i·m + j + 1, если i чётное;
значение = (i + 1)·m − j, если i нечётное.

Метод работает для любых прямоугольных матриц.

Змейка по столбцам (вертикальная)

Сверху вниз в чётных столбцах, снизу вверх — в нечётных:

значение = j·n + i + 1, если j чётное;
значение = (j + 1)·n − i, если j нечётное.

Порядок циклов — сначала по столбцам, потом по строкам — чтобы заполнять «по столбцам».

Змейка по квадрату (спираль)

Числа идут по спирали от левого верхнего угла по часовой стрелке внутрь. Алгоритм работает слоями: обходим внешний прямоугольный контур, сужаем границы, переходим к следующему внутреннему.

Алгоритм работает для любых прямоугольных матриц. При нечётном числе строк или столбцов центральный элемент заполняется последним. Проверки if (top <= bottom) и if (left <= right) нужны, чтобы на последнем «тонком» слое (одна строка или один столбец) не пройти его дважды.

Матрицы в проде повсюду: изображение — это матрица пикселей (поворот фото на 90° — транспонирование плюс отражение), игровое поле, таблица в Excel. А «спиральный обход» — задача Spiral Matrix с LeetCode, которую реально дают на собеседованиях в большие компании.
