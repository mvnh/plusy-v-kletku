# Плюсы в клетку

Интерактивная версия «Великого конспекта по C++» (М. Горденко, курс ВШЭ): те же 26 тем и та же строгость, плюс визуализации памяти, битов и матриц, задачи с автопроверкой и тренажёр к экзамену.

Код из примеров и задач собирает **твой** компилятор (g++ или clang++), поэтому всё работает так же, как в CLion: исключения, `sizeof(long) == 8`, предупреждения, санитайзеры.

## Быстрый старт (macOS, Linux)

```bash
cd plusy-v-kletku
bash start.sh
```

Скрипт сам проверит Python и компилятор C++ и поставит недостающее:
- **macOS** — Xcode Command Line Tools (там `clang++` и `python3`; `g++` на Mac — это тот же clang);
- **Linux** — `g++` и `python3` через apt, dnf, yum, pacman, zypper или apk.

Для установки может понадобиться пароль администратора и интернет. Потом откроется браузер с платформой. Повторные запуски сразу стартуют сервер. Опции передаются серверу: `bash start.sh --port 8800`.

На macOS можно просто дважды кликнуть `start.command` — он делает то же самое.

## Установка вручную

Если скрипт не подошёл. Нужны **Python 3.8+** и **компилятор C++**, больше ничего; после установки интернет не нужен.

**macOS.** Открой «Терминал» и выполни `xcode-select --install`. Это установит `clang++` и `python3`. Если они уже есть, команда об этом скажет.

**Linux.** `sudo apt install g++ python3` (или аналог для твоего дистрибутива).

**Windows.** Python с python.org (при установке отметь «Add to PATH»). Компилятор g++ ставится через MSYS2: `pacman -S mingw-w64-ucrt-x86_64-gcc`. Затем добавь `C:\msys64\ucrt64\bin` в `PATH`.

## Запуск

- **macOS/Linux:** `bash start.sh` или (macOS) двойной клик по `start.command`. В первый раз macOS может не пустить файл от неизвестного разработчика: правый клик → «Открыть» → «Открыть».
- **Windows:** двойной клик по `start.bat`.
- **Любая система:** в терминале, в папке платформы, выполни `python3 server.py`.

Браузер откроется сам на <http://127.0.0.1:8737>. Пока платформа нужна, окно терминала не закрывай. Остановить: `Ctrl+C`.

Дополнительные опции:

```bash
python3 server.py --port 8800       # другой порт, если 8737 занят
python3 server.py --cxx g++-14      # выбрать конкретный компилятор
python3 server.py --no-browser      # не открывать браузер автоматически
```

## ИИ-тьютор (необязательно)

ИИ работает через Claude API или OpenAI API — на выбор. Нужен свой ключ ([console.anthropic.com](https://console.anthropic.com) или [platform.openai.com](https://platform.openai.com)); оплата по факту использования. Без ключа ИИ-кнопки просто не работают, остальное доступно полностью.

```bash
# Claude
export ANTHROPIC_API_KEY=sk-ant-...           # Windows: set ANTHROPIC_API_KEY=sk-ant-...
export ANTHROPIC_MODEL=claude-sonnet-5-5      # необязательно, это значение по умолчанию

# или OpenAI
export OPENAI_API_KEY=sk-...                  # Windows: set OPENAI_API_KEY=sk-...
export OPENAI_MODEL=gpt-4.1                   # необязательно, это значение по умолчанию
export OPENAI_BASE_URL=https://api.openai.com/v1   # необязательно: любой OpenAI-совместимый сервер

python3 server.py
```

Если заданы оба ключа, по умолчанию используется Claude; чтобы переключиться, добавь `AI_PROVIDER=openai` (или `anthropic`). Какой ИИ сейчас подключён, сервер пишет в консоль при старте.

Ключ живёт только в переменной окружения сервера, в браузер он не попадает.

## Как этим пользоваться

1. **Глава → квизы → задачи главы.** Внизу каждой главы есть блок «Закрепим главу» со ссылками на подходящие задачи и вопросы «что выведет».
2. В задаче «**Запустить**» гоняет твой код на твоём вводе, а «**Проверить на тестах**» — на всех тестах, включая скрытые. В задачах вида «напиши функцию» свой `main` не нужен, проверяющий допишется сам.
3. Перед экзаменом: **флешкарты** каждый день по 10 минут и пару **пробных билетов**.
4. Не понял, почему код ведёт себя странно? Запусти его в песочнице с санитайзерами.

## Прогресс

Прочитанные главы, ответы на квизы, решённые задачи с кодом, коробки флешкарт и результаты билетов хранятся в браузере (`localStorage`). В другом браузере или в режиме инкогнито прогресс начнётся с нуля. Если очистить данные сайта, прогресс пропадёт.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Не нашёл компилятор C++» | macOS: `xcode-select --install`. Linux: поставь `g++`. Windows: проверь, что `g++ --version` работает в новом окне терминала. |
| «Порт 8737 занят» | `python3 server.py --port 8800` |
| Страница пишет «Сервер платформы не отвечает» | Окно терминала с сервером закрыто: запусти снова. |
| Санитайзеры не работают | На Windows/MinGW их нет, это ограничение компилятора. Используй обычный режим. |
| ИИ: `CERTIFICATE_VERIFY_FAILED` (macOS) | Запусти `Install Certificates.command` из папки Python в «Программах». |
| Программа «висит» | Лимит 4 секунды. Скорее всего, бесконечный цикл или программа ждёт ввода: заполни поле stdin. |

## Безопасность

Код, который ты запускаешь, выполняется на твоём компьютере с твоими правами, как в CLion. Поэтому:

- сервер слушает только `127.0.0.1` (с других устройств к нему не подключиться);
- запросы со сторонних сайтов отклоняются;
- каждый запуск идёт в отдельной временной папке, с лимитом 4 секунды и 200 000 символов вывода.

Не пробрасывай порт наружу и не запускай чужой код, которому не доверяешь.
